This project uses Selene for development.
Make sure that you read the project's `critical_info` memory before working on it.
* When using Selene, the memory is provided either
  - along with the result of the `initial_instructions` tool, or
  - upon activating the project with `activate_project`.
  Be sure to always call the `initial_instructions` tool!
* When not using Selene, read `./.selene/memories/critical_info.md` manually.<br>

Keep project data with the connected client. Do not upload code, logs, memories, credentials, or diagnostics to external services unless the user explicitly requests that transfer.
